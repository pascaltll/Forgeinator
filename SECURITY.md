# Security / Seguridad

Please do **not** open public issues for security problems (for example, a way to read another user's tokens or to run code through a crafted catalog or archive). Use GitHub's **Report a vulnerability** (Security tab) to report it privately.

Por favor **no** abras issues públicos para problemas de seguridad (por ejemplo, una forma de leer tokens o de ejecutar código con un catálogo o un archivo manipulado). Usa **Report a vulnerability** (pestaña Security) para avisar en privado.
